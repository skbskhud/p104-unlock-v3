# P104-100 自动版（Gen2 x4 + 宽度声明 x16）—— 备用方案

> ⚠️ **主推手动版**（`P104-2.0x16-Manual-v1.0.zip`）：最稳、最可控。
> 本自动版适合"想开机自动、且愿意等"的人。

## 它做什么

- 注册 SYSTEM 计划任务（开机 +60s / 登录 +15s / **每分钟自动重试**）；
- 任务启动后：写 BAR0 使能位 → 整卡复位 → 锁存 Gen2 → 两端 TLS/重训 → 常驻看门狗保持 → 写宽度声明 x16。

## 重要提醒（自动版的"脾气"）

- **冷启动后第一次整卡复位经常锁存失败**，要靠任务每分钟重试；
- 通常 **2–4 分钟**能成功，**有时会更久**（这台机器的实测就有多次失败后重试成功的记录）；
- 所以：**着急用 → 用手动版**；不着急、想开机即用 → 自动版。

## 用法

```
1) 解压 → 右键 install.cmd → 以管理员身份运行
2) 重启
3) 开机后等 2–4 分钟（任务会自动重试）
4) status.cmd 看 RESULT；bwtest.cmd 看实测带宽
5) 卸载：uninstall.cmd（管理员）
```

## 已验证 / 待验证

- ✅ 已验证（连续 4.5 小时）：常驻保持下 Gen2 x4，带宽 1.55 GB/s；宽度声明写入（LnkCap maxwidth=16）；
- ⏳ 待实测：干净重启后"开机自启"全流程（沿用 v1.6 流程，预计 2–4 分钟）；
- ⏳ 待实测：补 AC 耦合电容后物理链路能否真到 x16（预计可行，补完更新）。

## 注意

- BYOVD 驱动（WinRing0/ThrottleStop）杀软报警属预期；不要与其它 P104 工具同时运行；
- 宽度 x16 是**声明层**；物理宽度仍 x4，需补电容后由硬件决定；
- 极端掉卡：完全断电冷启动恢复（易失寄存器，不损坏硬件）。

## 只读：读取熔丝（用于跨卡对比/研究）

双击 读取熔丝.cmd（管理员，只读）→ 输出 P104/GP104 的熔丝寄存器值；
用来对比 GTX 1070/1080 等零售卡，核对 GEN3_DIS/媒体熔丝的位映射。
