# P104-100 手动版（Gen2 x4 + 宽度声明 x16）—— ⭐ 推荐

> **主推版本**：不注册任何任务/自启，双击 `手动解锁.cmd` 并保持窗口开着即可；
> 关掉窗口就停止。所见即所得，最稳、最可控。

## 用法

```
1) 解压 → 右键 手动解锁.cmd → 以管理员身份运行，保持这个窗口开着
2) 想检查：双击 状态.cmd（Gen2/声明宽度/带宽）
3) 想停止：关掉窗口，或双击 停止按住.cmd
```

## 已验证 / 待验证

- ✅ 已验证（连续 4.5 小时）：Gen2 x4 保持，带宽 1.55 GB/s；宽度声明写入（LnkCap maxwidth=16）；
- ⏳ 待实测：补 AC 耦合电容后物理链路能否真到 x16（预计可行，补完更新）。

## 说明

- 因为 NVIDIA 驱动每次 CUDA 初始化都会把链路降回 Gen1，所以要保持窗口**一直开着**，
  保持进程每 20ms 回写一次；关窗口链路就会掉回 1.1，这是正常的。
- 宽度 x16 是**声明层**；物理宽度仍 x4（要真 x16 需要补 AC 耦合电容/lane，预计可行、待实测）。
- BYOVD 驱动（WinRing0/ThrottleStop）杀软报警属预期；不要与其它 P104 工具同时运行。
- 极端掉卡：完全断电冷启动恢复（易失寄存器，不损坏硬件）。

## 文件

```
手动解锁.cmd   前台运行保持进程（管理员）
停止按住.cmd   结束保持进程
状态.cmd       状态 + 带宽
带宽测试.cmd   只测带宽
bin\           exe + 驱动
```

## 只读：读取熔丝（用于跨卡对比/研究）

双击 读取熔丝.cmd（管理员，只读）→ 输出 P104/GP104 的熔丝寄存器值；
用来对比 GTX 1070/1080 等零售卡，核对 GEN3_DIS/媒体熔丝的位映射。
