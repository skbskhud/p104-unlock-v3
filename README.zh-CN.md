# P104-100：PCIe Gen2 x4 解锁 + 宽度声明 x16（Windows）

**中文** | [English](README.md)

> NVIDIA **P104-100**（GP104 矿卡，`10DE:1B87`）专用 Windows 工具：
> 出厂 **Gen1 x4（≈0.78 GB/s）** → 解锁为 **Gen2 x4（实测 ≈1.57 GB/s）**，
> 同时写入 **宽度声明 x16**（`LnkCap maxwidth = 16`），并由常驻进程保持。
>
> **v3.2 起完整开源**：可执行工具 + 破解方法论 + Python 实验工具链。
> 配套文档见 [`docs/07-破解方法论与AI-Agent指南.md`](docs/07-破解方法论与AI-Agent指南.md)。

## 实测结果（2026-10-30，本机单卡，CPU 直连 x16 槽）

| 项目 | 结果 |
|---|---|
| 解锁路径 | **live 写组，无需整卡复位** |
| 出厂态 → Gen2 | **0 次复位、约 3 秒完成**（两次冷态复测：7.4 s / 2.8 s，均 PASS） |
| PCIe 链路 | **Gen2 x4**（`LNKSTA = 0x00001042`） |
| `LnkCap` 声明 | maxspeed = Gen2、**maxwidth = x16**（`0x00454D02`） |
| CUDA 带宽（页锁定） | **H2D 1.570 / D2H 1.673 GB/s**（Gen1 x4 参考 0.78 / 0.85） |
| 常驻保持 | 150 ms 看门狗，只在偏离时补写；历史实验连续保持 29 分钟无掉速 |
| 开机自启 | 计划任务：开机 +90 s / 登录 +120 s / 每 5 分钟自愈 |
| 失败兜底 | live 连续失败才做整卡复位，单次运行最多 1 次（同一开机周期最多 2 次、间隔 ≥10 分钟） |

> ⚠️ **宽度 x16 目前是"声明层"**：`LnkCap` 显示 `maxwidth = 16` 是真实写入的，
> 但物理只有 4 条 lane，实际链路仍是 x4，**带宽不会因为 x16 声明而提升**。
> 补 AC 耦合电容后能否真的训练到 x16，计划 **2026-10-31（周六）实测**，结果会更新到本仓库。

## 下载与使用

在本仓库根目录或 **Releases** 下载 `P104-2.0x16-v1.1.zip`：

1. **完整解压**到本地硬盘（不要在压缩包里直接双击）
2. 右键 `一键解锁.cmd` → **以管理员身份运行**
3. 看到 `SUCCESS` 即完成；再跑 `带宽测试.cmd`（H2D 应 ≥1.4 GB/s）
4. 日常查看：`状态.cmd`（只读，不需要管理员）
5. 想停止：`停止按住.cmd`；彻底卸载：`卸载.cmd`
6. 不想装自启：`手动解锁-仅实验用-窗口不能关.cmd`（**仅实验/排障**；窗口不能关，关窗口即停止。玩家日常请用一键解锁）

> **窗口能不能关？**
> - **一键解锁.cmd（推荐）：能关。** 看到 SUCCESS 后直接关窗口即可，保持进程在后台 SYSTEM 计划任务里，关机/重启后也会自动重新解锁。
> - **手动解锁-仅实验用-窗口不能关.cmd：不能关，且不推荐日常使用。** 这个窗口本身就是保持进程，关窗口 = 停止（链路回 Gen1 x4，属正常现象）。
> - **重复运行是安全的**：已经解锁后再运行一次，会检测到"已经是 Gen2 x4 + 声明 x16"，跳过所有写入/复位，只重启一次保持进程（链路可能短暂回落，几秒内自动恢复）。
包内 `.cmd` 全部是纯 ASCII + CRLF（v1.1 修复了旧版的输出乱码问题），说明见包内 `README.md`。

## 工作原理（v1.1）

1. 通过 BYOVD 驱动（WinRing0 / ThrottleStop）映射 GPU BAR0；
2. 写入 **live 声明写组**（实测可实时把 PCIe 声明从 Gen1 翻到 Gen2）：
   `0x8872C = 6` → `0x2241C |= 0x81` → `0x8841C &= ~0x6000` → `0x8C2C0 &= ~4`
   → `0x8C300 &= ~0x10` → `0x8C040 SPEED=1` → `0x8C1C0[19:16]=2` → `0x88610 |= 1`
   （写后 `LnkCap2` 的 Gen2 声明位在 1 秒内出现，无需复位）
3. 两端 `LNKCTL2 = 2`（5.0 GT/s）+ 根端口 retrain → 链路训练到 **Gen2 x4**；
4. 确认 Gen2 后写 **宽度声明 x16**：`0x8C040 = (cur & ~0xF8000000) | 0x80000000`
   （安全配方；回退永远整字写 `0x20085800`，禁止用掩码单 bit 清 bit31 —— 实测会掉卡）；
5. 150 ms 看门狗只在链路/声明/宽度偏离时补写（NVIDIA 驱动每次 CUDA 初始化会把 `0x8C040.SPEED` 降回 Gen1）；
6. 如果 live 路径连续失败（很少见），才做 **1 次**整卡复位兜底，复位后仍用 live 写组补一遍。

## 兼容性与安全

- Windows 10 / 11 x64 + **管理员权限**；只认 **P104-100（`10DE:1B87`）**；
- 已验证环境：CPU 直连 PCIe x16 槽（PCH 槽未实测；社区反馈可能只写 BAR0 就能锁存）；
- BYOVD 驱动（WinRing0 / ThrottleStop）可能被杀毒/反作弊拦截，属预期；
- **只写易失寄存器**：不刷 VBIOS、不烧熔丝、不改 VBIOS，断电即恢复；
- 只对自己拥有的硬件使用；
- 极端情况链路训练失败会把卡从总线打掉：**彻底断电 30 秒**即可恢复，工具会停手并提示，不会反复复位。
