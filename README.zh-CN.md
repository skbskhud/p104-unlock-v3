# P104-100 解锁与功能边界（v3.0）

**中文** | [English](README.md)

> NVIDIA **P104-100**（GP104 矿卡，`10DE:1B87`）实测：能解锁什么、锁死在什么层、证据是什么。

## 30 秒结论

| 能力 | 结果 |
|---|---|
| **PCIe Gen2 x4** | ✅ 可解锁（0.78 → 1.55 GB/s，已实测） |
| **声明宽度 x4→x16** | ✅ 主机侧可改（`LnkCap` 最大宽度变 16）；⚠️ 实际链路/带宽未验证，需补电容 |
| **PCIe Gen3** | ❌ 不可解（OTP 熔丝 `GEN3_DIS=1`） |
| **NVENC / NVDEC / OFA** | ❌ 不可解（OTP 熔丝 `NVDEC_DISABLE=1` / `NVENC_DISABLE=3` / `OFA_DISABLE=1`） |

完整证据、方法与覆盖边界 → [`docs/05-功能边界总表.md`](docs/05-功能边界总表.md)

## 使用（3 步）

```
1. 解压 → 双击 一键解锁.cmd（自动提权）
2. 一键验证.cmd：看「声明 Gen2 / 声明 x16 / 当前链路」
3. 不想要了：一键恢复.cmd（停任务 + 寄存器回出厂 + 删驱动）
```

- 保持进程每 100ms 复查补写，登录自启；
- 驱动为 BYOVD（WinRing0/ThrottleStop），安全软件报警属预期；
- 日志/状态：`%ProgramData%\P104Unlock\`。

## 重要声明（务必读）

- **宽度 x16 只是「声明层」可控**：未验证补电容后链路能真的训练到 x16，也不声称带宽提升。
- **Gen3 / 编解码器是 OTP 熔丝层**：主机侧无解；只剩物理熔丝攻击（不建议，不在范围）。
- 所有写入都是**易失寄存器**：不刷 VBIOS、不烧熔丝，断电即恢复。
- 仅用于研究自己拥有的硬件。
