# P104-100 功能边界报告 + 一键组合包 v3.0

**中文** | [English](README.md)

> NVIDIA **P104-100**（GP104 矿卡，`10DE:1B87`）的**功能边界实测**：
> 每一项能力到底能不能从主机侧打开、卡在哪一层、证据是什么。
> 同时提供 **v3.0 一键组合包**（Gen2 x4 + 宽度声明实验）。

---

## 结论速览

| 能力 | 结论 | 落点 |
|---|---|---|
| **PCIe Gen2 x4** | ✅ **可解**（0.78 → 1.55 GB/s 实测） | 寄存器层 |
| **声明宽度 x4→x16** | ✅ **主机侧可改**（`LnkCap` 最大宽度实时变 x16）；⚠️ **实际链路宽度未验证**，带宽暂无变化 | 寄存器层 + 物理层（待验证） |
| **PCIe Gen3** | ❌ **不可解**（OTP 熔丝 `GEN3_DIS=1`，证据链 6 条） | 熔丝层 |
| **NVENC / NVDEC / OFA** | ❌ **不可解**（OTP 熔丝 `NVDEC_DISABLE=1` / `NVENC_DISABLE=3` / `OFA_DISABLE=1`） | 熔丝层 |

> 一句话：**寄存器层能解的已经全解；固件层没有可写入口；熔丝层（Gen3、编解码器）是真正的墙。**

完整证据、方法与覆盖边界：**[`docs/05-功能边界总表.md`](docs/05-功能边界总表.md)**

## 怎么用（本机版）

```
1) 解压，双击 P104-一键组合包-v3.0/一键解锁.cmd（自动请求管理员）
2) 一键验证.cmd 看状态：
   - 声明 Gen2 = 1  (LnkCap2 = 0x00000006)
   - 声明 x16  = 1  (LnkCap maxwidth = 16)
   - 当前链路  = LnkSTA（x4 或 x16）
3) 补完 AC 耦合电容后重启（任务自动施加 + retrain）或手动 retrain
```

工具会以 100ms 看门狗保持状态，并注册 SYSTEM 登录任务；驱动为 BYOVD（WinRing0/ThrottleStop），
安全软件报警属预期。卸载：`一键恢复.cmd`（清任务 + 恢复寄存器 + 删驱动服务）。

## 重要声明（请务必读）

- **宽度 x16 只是「声明层」可控**：我们**没有**验证补电容后链路能真的训练到 x16，
  也不声称任何带宽提升。社区可自行实测，成功/失败都欢迎回报。
- **Gen3 与编解码器是 OTP 熔丝层限制**：寄存器/驱动/VBIOS/EFI 全部无解；
  理论上只剩物理熔丝攻击，不在本项目范围，也不建议。
- 所有写入都是**易失寄存器**：不刷 VBIOS、不烧熔丝，断电即恢复。
- 仅用于研究自己拥有的硬件；换平台/换卡后结论可能不同。
