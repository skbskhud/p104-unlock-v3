# P104-100 PCIe 2.0 x4 解锁 + 宽度声明 x16 一键组合包（v1.0）

> NVIDIA **P104-100**（GP104 矿卡，`10DE:1B87`）专用。
> **开机自动生效**：登录后约 60 秒，SYSTEM 计划任务自动把链路拉到 **Gen2 x4**，
> 并把 **宽度声明 x16** 一并置上；常驻看门狗每 20ms 保持，失败自动重试/自愈。

## 它能做什么（实测）

| 项目 | 结果 |
|---|---|
| **PCIe Gen2 x4** | ✅ 解锁（实测 **0.78 → 1.55 GB/s**，约 2 倍） |
| **宽度声明 x16** | ✅ 自动写入（`LnkCap` 最大宽度变 16） |
| **实际链路宽度** | 仍为 **x4**（物理 lane 只有 4；补 AC 耦合电容后才可能真正 x16，未验证） |
| PCIe Gen3 / 编解码器 | ❌ 熔丝锁死，本工具不做（见边界报告） |

> 说明：宽度 x16 是**声明层**。带宽提升来自 Gen2；x16 的实际带宽要等物理层（电容/lane）通后才会出现。

## 通用性

- **Windows 10 / 11 x64**，管理员权限；
- 用 .NET Framework 4.x（系统自带，**不需要安装 Python**，也不需要 VS）；
- 只认 **P104-100（10DE:1B87）**，不会碰别的显卡；
- Gen2 解锁依赖 **CPU 直连的 PCIe x16 根端口**（本项目是在 CPU 直连槽上验证的）；
  走芯片组转接/延长线的槽位可能不适用，需要自己实测；
- 每台机器首次运行会自动写驱动策略（`RMPcieLinkSpeed=1`）、部署到 `C:\Program Files\P104Gen2x4`、注册开机任务。

## 使用

```
1) 解压到任意目录（不要只解压一半）
2) 双击 一键解锁.cmd（管理员）   → 安装 + 立即解锁 + 状态
3) 建议重启一次（开机自动解锁生效；约 60 秒后完成）
4) 一键验证.cmd                  → 看 RESULT 一行
5) 带宽实测.cmd                  → 真实带宽（1.55 GB/s 左右 = Gen2 x4 成功）
6) 不想要了：一键恢复.cmd        → 删任务 + 恢复寄存器 + 删驱动
```

## 关于 "GPU-Z 显示 1.1 x4"

这张矿卡在空闲时 NVIDIA 驱动上报的链路信息不可信（常显示 1.1）。
以 **一键验证.cmd 的 RESULT 行** 和 **带宽实测** 为准。

## 注意

- 驱动是 BYOVD（WinRing0/ThrottleStop），**杀毒软件会报警**，属预期；
- 不要和其它 P104 工具同时运行（会互相抢寄存器）；
- 极少数情况下链路训练失败会让卡从总线上掉下来：**完全断电冷启动即可恢复**
  （写的是易失寄存器，不会损坏硬件）；
- 只用于研究自己拥有的硬件。
