# P104-100 一键组合包 v3.0（Gen2 x4 默认 + 宽度声明 x16 实验）

> **独立可运行**：自带 Python 运行时 + 驱动，不需要安装 Python；解压即用（管理员权限）。
> 只写**易失寄存器**：不刷 VBIOS、不烧熔丝，断电即恢复。

## 重要：默认行为已按安全方式调整（2026-10-29）

- **开机自启只做 Gen2 x4**（成熟路径，已验证）；
- **宽度声明 x16 改为手动开关**（`宽度x16-开.cmd` / `宽度x16-关.cmd`），不再随开机自动施加；
- 登录后**延迟 60 秒**才施加（等 NVIDIA 驱动完全初始化）；
- 施加过程中如果设备失去响应会**立即中止**，不再继续操作；
- 自动清理重启后残留的"硬件锁"（避免开机自启不生效）。

宽度 x16 **只是声明层**：实际链路宽度仍是 x4（`LNKSTA`），带宽没有变化；需要补 AC 耦合电容后由物理层决定是否能真的训练到 x16（未验证）。

## 使用

```
1) 解压到任意可写目录（装完不要移动，计划任务里记的是绝对路径）
2) 双击 一键解锁.cmd（自动提权）→ 装驱动 + 注册 SYSTEM 登录任务 + 立即施加 Gen2
3) 一键验证.cmd 看状态（可顺手 retrain）
4) 想试宽度声明：双击 宽度x16-开.cmd；撤销：宽度x16-关.cmd
5) 完全卸载：一键恢复.cmd（停任务 + 寄存器回出厂 + 删驱动服务）
```

日志/状态：`%ProgramData%\P104Unlock\`（`width16_hold.log` / `width16_state.json`）。

## 要求与风险

- Windows 10/11 x64、管理员权限、NVIDIA P104-100（`10DE:1B87`）；
- 驱动为 BYOVD（WinRing0/ThrottleStop），安全软件会报警（预期）；
- 不要把本工具与其它 P104 工具同时运行（单写者）；
- 极端情况下链路可能训练失败导致设备掉出总线：**完全断电冷启动即可恢复**（寄存器是易失的，不会损坏卡）；
- 仅供研究自己拥有的硬件。
