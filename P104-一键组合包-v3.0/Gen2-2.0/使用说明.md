# P104Gen2x4 v2.0-beta 使用说明（多卡 BETA）

> 这是 **v2.0-beta 多卡实验版**。单卡 P104-100 的稳定版仍是 v1.6，两者 exe 同名、计划任务名相同。
> 多卡逻辑**未经实机验证**：请先 `-list` / `-dry-run`，确认识别正确再真跑。

---

## 一、这是什么

把 NVIDIA 矿卡（P104-100 / P104-101 / P106-100 / P106-090）在 CPU 直连 PCIe 槽上
从 **Gen1** 解锁到 **Gen2**（P104-100 已实机验证：x4 带宽 0.78 → 1.55 GB/s）。

原理：卡开机时只向系统"声明" Gen1；必须做一次**真正的整卡复位**（SetupAPI 禁用→启用，
设备真的离开总线再回来）让 PCIe 核重新锁存 Gen2 声明，然后写两端 TLS + 重训。

v2.0 的变化：
- **多卡**：自动找所有受支持的卡，逐卡解锁；常驻循环里逐卡保持。
- **可扩展型号表**：P104-101 / P106 先标 EXPERIMENTAL（**默认只读**）。
- 新命令：`-list`（枚举，不需要管理员）、`-dry-run`（只读预演）。
- 状态文件支持多卡逐卡段落。

## 二、快速开始（单卡 / 多卡通用）

```
1) 解压整个 zip（不要只拿 exe，drivers 必须一起）
2) 只读确认（不需要管理员）：
      bin\P104Gen2x4.exe -list
   看 #0 / #1 ... 的 BDF、型号、级别是否正确。
3) 只读预演（会临时加载只读驱动读寄存器，不写、不复位）：
      bin\P104Gen2x4.exe -dry-run
4) 安装并常驻（右键“以管理员身份运行”）：
      install.cmd
   或先单次解锁看看：
      bin\P104Gen2x4.exe -once
5) 看状态：
      status.cmd          （不需要管理员）
```

安装后计划任务会在开机、登录、以及每分钟自愈时运行
`P104Gen2x4.exe -quiet -retry 3`（动作与 v1.6 完全一致），**多卡只跑一个实例**。

## 三、★ 多卡使用须知

```
1) 复位是一张一张做的（代码保证）：
   · 一次只复位一张卡；
   · 复位后等这张卡的声明锁存稳定（最多 20 秒，每 4 秒检查 LCAP2）再处理下一张；
   · 两次复位起点间隔 ≥3 秒；
   · 某张卡复位失败：记录日志后继续下一张，不会卡死整个流程。

2) 第一次接触多卡：先 -list，再 -dry-run，把输出留档；确认无误再 -once / install。

3) 按住循环里发现某张卡掉回 Gen1：只补写声明（不主动复位）。

4) 多卡按 BDF 编号（#0、#1...）。拔掉/换插槽后：按住进程每 30 秒重新枚举，
   不会死等旧 BDF；被拔掉的卡移出，新出现的卡会重新识别并尝试解锁。

5) EXPERIMENTAL 型号（P104-101 / P106-100 / P106-090）默认只读：
   只检测、不写入、不复位、不写驱动策略。确实要试必须显式：
      bin\P104Gen2x4.exe -once -force-experimental
   ★ 配方是 P104/GP104 验证过的，在 GP106 上未验证 —— 风险自负。

6) 出问题排查：
   · status.cmd                → 顶部/底部 RESULT + 逐卡行
   · 管理员运行 bin\P104Gen2x4.exe -diag    → 寄存器级数据
   · 卡没回来/一直不锁存 → 重启机器（不会损坏硬件）
   · 想彻底还原 → 管理员运行 bin\uninstall.cmd，然后重启

7) 回退到 v1.6：计划任务名和参数相同，直接用 v1.6 的 exe 覆盖即可；
   稳妥做法是先 uninstall 再装 v1.6。
```

## 四、命令一览

| 命令 | 需要管理员 | 作用 |
|---|---|---|
| （无参数） | 是 | 完整解锁 + 常驻按住（多卡逐卡） |
| `-once` | 是 | 只解锁一次，不常驻 |
| `-status` / `-check` | 否 | 只读状态（读按住进程写的状态文件） |
| `-list` | 否 | 枚举所有 NVIDIA 卡（不需要驱动） |
| `-dry-run` | 否* | 只读预演，显示每张卡"将会执行什么" |
| `-diag` | 是 | 寄存器级诊断 |
| `-off` | 是 | 还原寄存器（卸载脚本会调用） |
| `-install` / `-uninstall` | 是 | 安装 / 卸载 |
| `-vbios [-save x.rom]` | 是 | 读 VBIOS 并算 MD5/SHA256（只读） |
| `-version` / `-help` | 否 | 版本 / 帮助 |

\* `-dry-run` 若需要读原始寄存器会临时加载只读驱动（不写入）；没有管理员时退化为 PnP 级信息。

常用选项：`-quiet`（后台日志）、`-retry N`（**每张卡**最多复位 N 次，默认 1）、
`-noreset`（不复位）、`-card N`（只操作第 N 张）、`-force-experimental`（实验型号写入）。

## 五、状态文件

`C:\ProgramData\P104Gen2x4\当前状态.txt`（原子写，可随时打开）：

```
=== 卡 #0  01:00.0  P104-100 [VERIFIED] ===
当前链路速率 : Gen2 (5.0GT/s) x4
声明 : LNKCAP=... LCAP2=... TLS=2 (含 Gen2)
采样 : N 次   补写 : M 次   复位 : K 次
状态 : 正常（已解锁并在保持）
```

判据：**LNKSTA[3:0] = 2 才是 Gen2**；端点与上游根端口两端应一致。
GPU-Z / nvidia-smi 显示 Gen1 是正常的（它们读驱动上报值，矿卡上不可靠）。

## 六、风险 / 回退

- 整卡复位会让画面黑一下（每卡默认只复位 1 次；多卡是**逐张**黑，不是同时黑）。
- 工具会临时加载两个 BYOVD 驱动（WinRing0 / ThrottleStop），玩带反作弊游戏前先卸载。
- 多卡功能未经实机验证；发现问题请保留 `C:\ProgramData\P104Gen2x4\status.txt` 日志反馈。
- 回退：管理员运行 `bin\uninstall.cmd`（删任务 / 停服务 / 清驱动策略 / 还原寄存器）→ 重启。
